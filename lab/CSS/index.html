1. The Three Types of CSS

🔴 Inline CSS
Highest priority
🟢 Internal CSS
One page
🔵 External CSS
Reusable

Type A: Inline CSS

Applied directly to an element using the style attribute.

This paragraph uses inline CSS: color:#e74c3c; font-size:1.1rem;

Another inline styled paragraph — monospace font, letter-spacing, green color.

Type B: Internal CSS

Defined in the <style> tag inside <head>. Applied to this page only.

This element uses an internal-CSS class: Internal CSS Class

Type C: External CSS

Stored in a separate styles.css file, linked via <link rel="stylesheet" href="styles.css">.

All the layout, colors, typography, and animations on this page come from the external sheet.

Cascade Priority: Inline (1000) > ID (100) > Class (10) > Element (1)

3. CSS Box Model

Every element is a rectangular box: Content → Padding → Border → Margin

Content Area
  • Content: 220×80px
  • Padding: 20px on all sides
  • Border: 6px solid blue
  • Margin: 16px auto (centered)
  • box-sizing: border-box ensures predictable sizing

Total rendered width = content + padding×2 + border×2 = 220 + 40 + 12 = 272px (without border-box).
